# Remy product

## Goal

Telegram bot for reminders and todo management.

## MVP

Example:

User:
"Напомни 19.10.2026 в 15:00 позвонить врачу"

System:
- parses date/time;
- creates reminder;
- persists reminder;
- sends Telegram message at the requested time.

## Not in MVP

- Google Calendar
- Google Tasks
- recurring tasks
- task rescheduling
- AI planning
- multiple notification channels
